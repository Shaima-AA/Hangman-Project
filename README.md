# Project Name
Hangman Game

## Technologies Used
1. HTML
2. CSS
3. JavaScript

## Description
Hangman is a classic word-guessing game. The program picks a secret word at random and shows it as a row of blanks. On each turn the player guesses one letter: if the letter is in the word, every matching position is revealed; if not, the player loses one attempt. The player wins by uncovering the whole word before the attempts run out, and loses if the attempts reach zero.

## User Stories
1. As a user, i want to start a new game: a random hidden word is shown as blanks, along with the remaining attempts.

2. As a user, i want to guess a letter: a correct guess reveals every matching position, and a wrong guess costs one attempt.

3. As a user, i want to see my progress: the display shows the partial word, guessed letters and wrong guesses.

4. As a user, i want to get feedback on invalid or repeated input: non-letters and repeated letters show a message and don’t cost an attempt.

5. As a user, i want to win, lose, and play again: the game announces the result, reveals the word on a loss, and offers a new round.
