# Project Name
Hangman Game

## Technologies Used
1. HTML
2. CSS
3. JavaScript

## Description
Hangman is a classic word-guessing game. The program picks a secret word at random and shows it as a row of blanks. The player guesses one letter: if the letter is in the word, every matching position is revealed; if not, the player loses one attempt. The player wins by uncovering the whole word before the attempts run out, and loses if the attempts reach zero.

## User Stories
1. As a user, i want to start a new game: clicking Start picks a random word from a list of countries, foods and animals, shows it as blanks, and shows a hint with its category (Country, Food or Animal).

2. As a user, i want to guess a letter by clicking the on-screen A–Z buttons: a correct guess reveals every matching position in the word and hides that letter button, and a wrong guess turns the button red with and costs one attempt.

3. As a user, i want to see my progress: the blanks show the letters i have found so far, a hangman picture adds one body part for each wrong guess, and a heart disappears for each attempt i lose (6 wrong guesses are allowed).

4. As a user, i want used letters to be locked: a letter i already picked can't be clicked again, so it never costs me an extra attempt.

5. As a user, i want to win, lose, and play again: "You won!" appears when i complete the word, "You lost! The word was ..." reveals the word when i run out of attempts, the letter buttons are disabled when the game ends, and the Play Again button starts a new round.
